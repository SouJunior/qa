# qa
Organograma da Vertical de QA – SouJunior

Este é o organograma da Vertical de QA em formato pronto para usar no README.md do GitHub.

Estrutura Organizacional
Descrição dos Papéis

Head de QA

    * Lidera a vertical de qualidade.

    * Define estratégia e direcionamento de QA.

    * Conecta QA com as lideranças dos projetos.

Mentores de QA

    * Acompanham e desenvolvem os voluntários.

    * Compartilham boas práticas de testes.

    * Apoiam tecnicamente as squads.


Analistas de QA (Voluntários)

    * Atuam diretamente nas squads.

    * Executam testes e validam entregas.


QA Automation (quando aplicável) 

    Contribuem com automação de testes

    Melhoria da eficiência dos processos de qualidade.
